2. Uma janela do terminal irá abrir
3. O navegador abrirá automaticamente em: http://localhost:8000/login.html


📋 OPÇÃO 2: Rodar manualmente
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASSO 1 - Abrir terminal
-------------------------
Aperte: Windows + R
Digite: cmd
Aperte: Enter


PASSO 2 - Navegar até a pasta do projeto
-----------------------------------------
cd C:\Users\vicen\Gerenciador-de-Projetos-de-Engenharia-3\backend


PASSO 3 - Iniciar o backend
----------------------------
python app.py


PASSO 4 - Abrir o navegador
----------------------------
Abra seu navegador (Chrome, Edge, Firefox) e acesse:
http://localhost:8000/login.html

🛑 COMO PARAR O SISTEMA
═══════════════════════════════════════════════════════════════

1. Vá até a janela do terminal onde o backend está rodando
2. Aperte: Ctrl + C
3. Ou simplesmente feche a janela do terminal


═══════════════════════════════════════════════════════════════

❓ PROBLEMAS COMUNS
═══════════════════════════════════════════════════════════════

ERRO: "Address already in use" ou porta ocupada
SOLUÇÃO: Outra instância já está rodando. Feche-a primeiro.

ERRO: "ModuleNotFoundError"
SOLUÇÃO: Instale as dependências:
         cd backend
         python -m pip install -r requirements.txt

ERRO: Página não carrega no navegador
SOLUÇÃO: Verifique se o terminal mostra:
         "Uvicorn running on http://0.0.0.0:8000"
