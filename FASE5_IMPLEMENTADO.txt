🚀 COMO USAR:

1. DESENVOLVIMENTO LOCAL:
   ───────────────────────
   cd backend
   python app.py
   
   Acesso: http://localhost:8000/login.html

2. TESTAR PWA:
   ───────────
   - DevTools (F12) → Application
   - Verificar "Service Workers"
   - Ou menu do navegador: "Instalar aplicativo"

3. TESTAR SEGURANÇA:
   ──────────────────
   No console JavaScript:
   > window.securityManager.getSecurityInfo()
   
   Resultado esperado:
   {
     "authenticated": true,
     "roles": ["admin", "gerente"],
     "permissions": [...],
     "sessionTimedOutMinutes": 30,
     ...
   }

4. FAZER DEPLOY EM PRODUÇÃO:
   ─────────────────────────
   a) Escolher provedor (Railway recomendado)
   b) Conectar GitHub
   c) Adicionar variáveis de ambiente
   d) Push para main ativa deploy automático
   
   Seguir: DEPLOYMENT_GUIDE.md
